void и int: void — метод ничего не возвращает, а int — возвращает целое число через return.
return: завершает выполнение метода и возвращает результат, если он предусмотрен.
Перегрузка методов: создание нескольких методов с одинаковым именем, но разными параметрами. Компилятор выбирает нужный по количеству, типам и порядку параметров.
Можно ли различать методы только типом возврата? Нет, потому что компилятор не сможет однозначно выбрать метод по одному имени и одинаковым параметрам.
Пример разделения кода: в программе магазина можно создать метод CalculateTotal() для подсчёта стоимости покупок и ApplyDiscount() для применения скидки.
Вызов метода из другого метода: позволяет использовать готовый код повторно, не дублируя его, и делает программу понятнее.
